# 💊 Telegram Бот для нагадувань про прийом ліків за медичним висновком

Розумний Telegram-бот, який приймає фотографії (або текст) консультативних медичних висновків лікаря, аналізує їх за допомогою штучного інтелекту (Gemini Vision) і автоматично розраховує графік щоденних нагадувань про прийом ліків з урахуванням режиму харчування користувача.

---

## 🌟 Основні можливості

- 📷 **Розпізнавання медичних висновків з фото**: достатньо надіслати фотографію рецепта або консультативного висновку (наприклад, з клініки «Оксфорд Медікал»).
- 🧠 **Автоматичний аналіз призначень**: ШІ виділяє:
  - Назви препаратів (наприклад: *Меверин*, *Креон 10 000*, *Дуфалак*, *УДХК/Урсосан*)
  - Дозування (капсули, мг, мл)
  - Частоту прийому на день (1, 2, 3 рази)
  - Залежність від їжі (за 20 хв до їди, під час їди, після вечері, на ніч)
  - Тривалість курсу лікування (7 днів, 2 тижні тощо) та важливі примітки.
- ⏰ **Розумний розклад під ваш день**:
  - Графік їжі налаштовується користувачем (сніданок, обід, вечеря, сон).
  - Нагадування надсилаються автоматично у потрібний момент (наприклад, за 20 хв до сніданку та вечері).
- 🔔 **Інтерактивні кнопки**:
  - `✅ Прийняв(ла)` — фіксація прийому в журналі.
  - `⏰ Відкласти на 15 хв` — повторне нагадування.
- 📋 **Керування ліками**: перегляд активних курсів, скільки днів залишилося, можливість завершити прийом.
- 🏁 **Сповіщення про закінчення курсу**: коли термін прийому добігає кінця, бот нагадає про завершення або необхідність контрольного візиту / зміни дозування.

## 🚀 Швидкий запуск

### 1. Отримання ключів
1. **Telegram Bot Token**:
   - Відкрийте [@BotFather](https://t.me/BotFather) в Telegram.
   - Надішліть команду `/newbot`, оберіть ім'я та юзернейм для бота.
   - Скопіюйте наданий `token`.

2. **Google Gemini API Key**:
   - Перейдіть на [Google AI Studio](https://aistudio.google.com/app/apikey).
   - Натисніть **Create API key** (доступно безкоштовно).
   - Скопіюйте ключ.

### 2. Налаштування файлу `.env`
Відкрийте файл `.env` у папці проекту та вставте ваші ключі:

```env
BOT_TOKEN=123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ
GEMINI_API_KEY=AIzaSy...ваш_ключ_gemini...
TIMEZONE=Europe/Kyiv
```

### 3. Запуск бота
У терміналі виконайте:

```powershell
.\.venv\Scripts\python bot.py
```

## 📱 Як користуватися ботом у Telegram

1. Натисніть `/start`. Бот познайомиться з вами і покаже базовий графік дня (08:30 сніданок, 13:30 обід, 19:30 вечеря, 22:30 сон).
2. За потреби змініть години у меню **⚙️ Мій графік їжі**.
3. Надішліть фото висновку лікаря (або натисніть кнопку **📷 Додати висновок**).
4. Зачекайте кілька секунд — бот покаже виявлені препарати та точний розрахований час нагадувань.
5. Натисніть **✅ Активувати всі нагадування**.
6. Отримуйте своєчасні сповіщення з кнопками підтвердження прийому ліків!
